## 2. 학습 방법

### 모델 구조

```
이미지 → SK2Res2Net-101 백본 → 2048차원 특징 ─┐
                                            ├→ FusionModule → 변조된 특징 → FC → 107 클래스
상품크기(w,h) → sin/cos 인코딩(4차원) → FCNet ┘   (Dynamic MLP, variant C)
```

- **백본**: SK2Res2Net-101 (Res2Net 다중 스케일 + SK attention)
- **Dynamic MLP** (`mlp_type=c`, `mlp_d=256`, `mlp_h=64`, `mlp_n=2`): 상품 크기 임베딩으로 동적 가중치를 생성해 이미지 특징을 변조
- **메타데이터**: 어노테이션의 상품 물리 크기(width/height) → `encode_loc_time` → `[sin(πw), sin(πh), cos(πw), cos(πh)]` 4차원

### 하이퍼파라미터

| 항목 | 값 |
|---|---|
| batch_size | 256 (151 iter/epoch) |
| optimizer | SGD (momentum=0.9, weight_decay=1e-4) |
| start_lr | 0.02 (단일 GPU·batch 256에 맞춰 원본 0.04에서 축소) |
| LR 스케줄 | warmup 2 epoch (선형) → cosine decay → 0 |
| 손실 함수 | LabelSmoothingLoss (smoothing=0.1) |
| mixup | alpha=0.4 (이미지와 메타데이터를 동일 lam으로 혼합) |
| 증강 | Resize(256) → CenterCrop(224) → RandomHorizontalFlip → ImageNet 정규화 |
| 정밀도 | AMP (fp16 혼합정밀도) |
| 총 epoch | 100 |
| num_workers | 8 |

### 실행 명령

```bash
CUDA_VISIBLE_DEVICES=0 python3 train.py \
  --name sk2_dynamic_mlp \
  --data NIA29_input \
  --data_dir datasets \
  --model_file sk2res2net_dynamic_mlp \
  --model_name sk2res2net101 \
  --pretrained \
  --batch_size 256 \
  --num_workers 8 \
  --start_lr 0.02 \
  --stop_epoch 100 \
  --warmup 2
```

### 학습 곡선 해석

- **초기(1~10 epoch)**: 급격한 상승 (26.8% → 73.5%). ImageNet 사전학습 백본 덕분에 빠르게 수렴.

- **후기(80~100 epoch)**: 79% 전후에서 포화. epoch 84에서 최고치 달성 후 100까지 큰 변동 없음 → 수렴 완료로 판단됨.

## 4. 학습 중 발생한 이슈와 해결

| 이슈 | 원인 | 해결 |
|---|---|---|
| `ValueError: KAN_code 1116 not found` | `kan_code_list`(107개)에 없는 코드 5개가 데이터에 포함됨 | `dataset.py`/`prepare_data.py`에 리스트 외 코드 필터링 추가 → train 183장/tta 53장 제외 후 재학습 |
| `pip install thop` 실패 | PyTorch 인덱스에 `thop` 없음 | PyPI를 `--extra-index-url`로 추가 (thop은 FLOPs 측정용 옵션이라 생략 가능) |
| `--pretrained` 경로 오류 | `/workspace/PRETRAINS/...` 하드코딩 | `checkpoints/sk2res2net101_epoch_300.pth`로 수정 후 GitHub 릴리스에서 다운로드 |
| 간헐적 `data_time` 스톨 (~19초) | 데이터셋이 NFS 네트워크 디스크에 위치 | 이번 학습은 그대로 진행(후반부에는 스톨 감소). 향후 로컬 디스크 복사 시 학습 시간 대폭 단축 가능 |

### 시간 분석

- 예상: ~12시간 → 실제: **5.5시간** (NFS 스톨이 후반에 감소)
- 순수 연산 기준 iter당 0.47초 vs 실측 평균 ~2.7초 → 데이터 로딩 오버헤드 존재
- 로컬 디스크 사용 시 동일 학습 약 3시간 내외로 단축 가능할 것으로 추정

## 5. 향후 개선 방향

1. **상세 평가**: `eval.py`로 클래스별 confusion matrix 확인 → 성능이 낮은 클래스 파악
2. **데이터 보강**: 샘플이 부족한 클래스 증강 또는 추가 수집
3. **미사용 클래스 정리**: 107개 중 실제 데이터가 없는 13개 클래스 처리 방향 결정
4. **메타데이터 정규화 버그**: `dataset.py` 106~115줄의 중복 정규화 이슈 — 재학습이 수반되므로 별도 실험으로 검토
5. **I/O 최적화**: 데이터셋을 로컬 디스크로 복사해 학습 시간 단축
6. **image-only 대조 실험**: Dynamic MLP(크기 메타데이터)의 실제 기여도를 확인하려면 `--image_only` 백본과 성능 비교 권장
